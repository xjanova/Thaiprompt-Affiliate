## ภาพรวมระบบ

### ระบบดูดวง AI คืออะไร?

ระบบดูดวง AI เป็นระบบตอบคำถามดูดวงอัตโนมัติที่ใช้ปัญญาประดิษฐ์ (AI) ในการทำนายดวงชะตา รองรับการใช้งานผ่าน:

- **Facebook Messenger** - รับคำถามผ่านแชท Messenger ของเพจ
- **LINE Official Account** - รับคำถามผ่าน LINE OA (รองรับ Flex Message สวยงาม)

### บริการที่มี

| บริการ | ราคา | รายละเอียด |
|--------|------|------------|
| **ดูดวงพื้นฐาน** | ฟรี | ทำนายเรื่องทั่วไป 1 คำถาม |
| **ดูดวงละเอียด** | 49 บาท | ทำนายเชิงลึก 3 คำถาม พร้อมวันเกิด |

## วิธีใช้งานสำหรับลูกค้า

### Facebook Messenger

#### 1. เริ่มต้นใช้งาน

1. เข้าไปที่เพจ Facebook ที่เชื่อมต่อกับระบบ
2. กดปุ่ม **"ส่งข้อความ"** หรือ **"Messenger"**
3. กดปุ่ม **"เริ่มต้นใช้งาน"** (Get Started)
4. ระบบจะส่งข้อความต้อนรับ:

```
✨ สวัสดีค่ะ คุณ[ชื่อ]!

🔮 ยินดีต้อนรับสู่ระบบดูดวง AI
ทางเพจพร้อมทำนายดวงชะตาให้คุณค่ะ

═══════════════════════
📋 บริการของเรา
═══════════════════════

🆓 ดูดวงพื้นฐาน (ฟรี)
ทำนายเรื่องทั่วไป ความรัก การงาน การเงิน

💎 ดูดวงละเอียด (49 บาท)
ทำนายเชิงลึก 3 คำถาม พร้อมวันเกิด
```

#### 2. ดูดวงพื้นฐาน (ฟรี)

**วิธีที่ 1:** พิมพ์คำว่า `ดูดวง` ตามด้วยเรื่องที่อยากรู้
```
ดูดวงความรัก
ดูดวงการงาน
ดูดวง เรื่องการเงินปีนี้
```

**วิธีที่ 2:** พิมพ์คำถามโดยตรง
```
ปีนี้จะมีคู่ครองไหม
ควรเปลี่ยนงานไหม
การเงินเดือนหน้าเป็นอย่างไร
```

**ตัวอย่างคำตอบจาก AI:**
```
🔮 คำทำนายสำหรับคุณ

ดวงความรักของคุณในปีนี้มีแนวโน้มที่ดีค่ะ
ช่วงเดือนมีนาคม-พฤษภาคมจะมีโอกาสพบคนพิเศษ...

═══════════════════════
🔖 เลขที่บิลอ้างอิง
📌 FTN-20260205-A1B2C3
═══════════════════════

💎 ต้องการดูดวงละเอียดเพิ่มเติมไหมคะ?
ราคา 49 บาท ได้ถาม 3 คำถาม
พร้อมวิเคราะห์จากวันเกิด

พิมพ์ "ต้องการ" เพื่อดูดวงละเอียดค่ะ
```

#### 3. ดูดวงละเอียด (49 บาท)

**ขั้นตอนที่ 1:** ตอบว่า "ต้องการ" หรือ "ละเอียด"

**ขั้นตอนที่ 2:** ระบบจะถามวันเกิด
```
กรุณาบอกวันเกิดของคุณค่ะ (วัน/เดือน/ปี พ.ศ.)
ตัวอย่าง: 15/03/2533

หรือจะบอกแบบนี้ก็ได้ค่ะ:
• 15 มีนาคม 2533
• 15-03-2533
```

**ขั้นตอนที่ 3:** ระบุ 3 คำถามที่ต้องการ
```
กรุณาพิมพ์คำถาม 3 ข้อที่ต้องการทราบค่ะ
(พิมพ์ทีละข้อ หรือรวมในข้อความเดียวก็ได้)

ตัวอย่าง:
1. ดวงความรักปีนี้
2. ควรลงทุนหุ้นไหม
3. จะได้เลื่อนตำแหน่งเมื่อไหร่
```

**ขั้นตอนที่ 4:** ระบบแสดงบิลชำระเงิน
```
🧾 สรุปรายการ
═══════════════════════
📋 ดูดวงละเอียด - 3 คำถาม
💰 ยอดชำระ: 49.37 บาท

📌 เลขที่บิล: FTN-20260205-A1B2C3

🏦 ช่องทางชำระเงิน
═══════════════════════
ธนาคาร: กสิกรไทย
เลขบัญชี: 123-4-56789-0
ชื่อบัญชี: บริษัท ไทยพร็อมท์ จำกัด

⚠️ สำคัญ: โอนยอดเงิน 49.37 บาท
(ตรงตัวทุกสตางค์เพื่อระบบตรวจสอบอัตโนมัติ)

หลังโอนเงินแล้ว รอสักครู่ค่ะ
ระบบจะส่งคำทำนายให้อัตโนมัติ ✨
```

**ขั้นตอนที่ 5:** โอนเงินตามยอดที่แจ้ง
- โอนเงินตรงยอด **49.37 บาท** (ยอดไม่ซ้ำกัน)
- ระบบจะตรวจจับการโอนเงินอัตโนมัติผ่าน SMS

**ขั้นตอนที่ 6:** รับคำทำนายละเอียด
```
🌟 คำทำนายเชิงลึกสำหรับคุณ[ชื่อ]
═══════════════════════
📅 วันเกิด: 15 มีนาคม 2533
⭐ ราศี: มีน (Pisces)

🔮 วิเคราะห์ดวงชะตา
═══════════════════════

💕 คำถามที่ 1: ดวงความรักปีนี้
[คำทำนายละเอียด...]

💼 คำถามที่ 2: ควรลงทุนหุ้นไหม
[คำทำนายละเอียด...]

📈 คำถามที่ 3: จะได้เลื่อนตำแหน่งเมื่อไหร่
[คำทำนายละเอียด...]

═══════════════════════
🍀 สีมงคล: ม่วง, ฟ้า
🔢 เลขมงคล: 3, 7, 12
═══════════════════════

ขอให้โชคดีค่ะ ✨🔮
```

### LINE Official Account

#### 1. เริ่มต้นใช้งาน

1. Add Friend LINE Official Account ที่เชื่อมต่อกับระบบ
2. เมื่อ Add Friend สำเร็จ จะได้รับข้อความต้อนรับ (Flex Message)
3. กดปุ่ม **"🔮 เริ่มดูดวง"** หรือพิมพ์ "ดูดวง"

#### 2. การใช้งาน

การใช้งานเหมือนกับ Facebook Messenger ทุกประการ:
- พิมพ์ "ดูดวง" + เรื่องที่อยากรู้
- หรือพิมพ์คำถามโดยตรง

**ความแตกต่างจาก Facebook:**
- ใช้ Flex Message สวยงามและโต้ตอบง่าย
- มีปุ่มกดเลือกแทนการพิมพ์
- รองรับ Rich Menu (เมนูด้านล่าง)

## การตั้งค่าสำหรับ Admin

### ตั้งค่า Facebook Messenger

#### 1. สร้าง Facebook App และ Page

1. ไปที่ [Facebook Developers](https://developers.facebook.com/)
2. สร้าง App ใหม่ → เลือก "Business"
3. เพิ่ม Product → เลือก "Messenger"
4. เชื่อมต่อกับ Facebook Page

#### 2. ตั้งค่า Webhook

1. ที่ Messenger Settings → Webhooks → กด "Add Callback URL"
2. ใส่ Webhook URL:
   ```
   https://yourdomain.com/webhook/facebook/fortune
   ```
3. ใส่ Verify Token (ตั้งเองได้)
4. Subscribe events:
   - `messages`
   - `messaging_postbacks`

#### 3. ตั้งค่าในระบบ Admin

1. ไปที่ **Admin → ระบบดูดวง → การตั้งค่า**
2. กรอกข้อมูล:
   - **Facebook Page ID** - ID ของ Page
   - **Page Access Token** - Token จาก Facebook Developer
   - **App Secret** - สำหรับ verify webhook signature

#### 4. ตั้งค่าปุ่ม Get Started

1. ไปที่ **Admin → ระบบดูดวง → ช่องทางรับข้อความ**
2. ที่การ์ด Facebook กดปุ่ม **"ตั้งค่าปุ่มเริ่มต้น"**
3. ระบบจะตั้งค่า:
   - ปุ่ม Get Started (เริ่มต้นใช้งาน)
   - Greeting Text (ข้อความต้อนรับก่อนส่งข้อความแรก)
   - Persistent Menu (เมนูถาวร)

---

### ตั้งค่า LINE Official Account

#### 1. สร้าง LINE Official Account

1. ไปที่ [LINE Official Account Manager](https://manager.line.biz/)
2. สร้างบัญชีใหม่ (ฟรี หรือ Premium)

#### 2. เปิดใช้งาน Messaging API

1. ที่ Settings → Messaging API → Enable
2. จะถูกพาไป LINE Developers Console

#### 3. ดึงข้อมูล Channel

ที่ [LINE Developers Console](https://developers.line.biz/console/):

1. **Basic settings**:
   - Channel ID
   - Channel Secret

2. **Messaging API**:
   - กด "Issue" เพื่อสร้าง Channel Access Token (Long-lived)

#### 4. ตั้งค่า Webhook

1. ที่ Messaging API settings → Webhook settings
2. ใส่ Webhook URL:
   ```
   https://yourdomain.com/webhook/line/fortune
   ```
3. เปิด **"Use webhook"**

#### 5. ปิด Auto-reply

1. ไปที่ LINE Official Account Manager
2. Settings → Response settings
3. ปิด **"Auto-reply messages"**

#### 6. ตั้งค่าในระบบ Admin

1. ไปที่ **Admin → ระบบดูดวง → ช่องทางรับข้อความ**
2. กรอกข้อมูล LINE:
   - **Channel ID**
   - **Channel Secret**
   - **Channel Access Token**
3. เปิดสวิตช์ "เปิดใช้งาน LINE"
4. กด **"ทดสอบการเชื่อมต่อ"** เพื่อตรวจสอบ

## ระบบชำระเงิน

### Unique Payment Amount

ระบบใช้ยอดเงินไม่ซ้ำกันเพื่อจับคู่การชำระเงินอัตโนมัติ:

```
ราคาปกติ: 49.00 บาท
ยอดที่ลูกค้าโอน: 49.37 บาท (สุ่มทศนิยม)
```

**ทำไมต้องใช้ยอดไม่ซ้ำ?**
- ระบบตรวจจับ SMS แจ้งเตือนเงินเข้า
- จับคู่ยอดเงินกับบิลที่รอชำระโดยอัตโนมัติ
- ไม่ต้องให้ลูกค้าแจ้งสลิป

### Flow การชำระเงิน

```
1. ลูกค้าต้องการดูดวงละเอียด
   ↓
2. ระบบสร้างบิลพร้อมยอดไม่ซ้ำ (เช่น 49.37 บาท)
   ↓
3. ลูกค้าโอนเงินตามยอดที่แจ้ง
   ↓
4. ธนาคารส่ง SMS แจ้งเตือนเงินเข้า
   ↓
5. ระบบ SMS Checker ตรวจจับ SMS
   ↓
6. จับคู่ยอดเงินกับบิลที่รอชำระ
   ↓
7. อัพเดทสถานะบิลเป็น "ชำระแล้ว"
   ↓
8. AI สร้างคำทำนายละเอียด
   ↓
9. ส่งคำทำนายกลับไปยังลูกค้า (Messenger/LINE)
```

## การจัดการหลังบ้าน

### Admin Panel

#### 1. Dashboard

เส้นทาง: **Admin → ระบบดูดวง → ภาพรวม**

แสดง:
- สถิติคำทำนายวันนี้ / เดือนนี้
- รายได้รวม
- กราฟแนวโน้ม
- คำทำนายล่าสุด

#### 2. ประวัติการทำนาย

เส้นทาง: **Admin → ระบบดูดวง → ประวัติการทำนาย**

- ดูรายการคำทำนายทั้งหมด
- กรองตามวันที่ / ช่องทาง / สถานะ
- ดูรายละเอียดแต่ละคำทำนาย
- Export เป็น CSV

#### 3. จัดการบิล

เส้นทาง: **Admin → ระบบดูดวง → จัดการบิล**

- ดูบิลที่รอชำระ / ชำระแล้ว
- ยืนยันการชำระเงินแบบ Manual
- ยกเลิกบิล

#### 4. การตั้งค่า

เส้นทาง: **Admin → ระบบดูดวง → การตั้งค่า**

ตั้งค่าได้:
- **AI Provider** - Grok, OpenAI, Google
- **ราคาดูดวงละเอียด**
- **จำนวนคำทำนายฟรี/วัน**
- **ข้อมูลบัญชีธนาคาร**
- **Facebook/LINE credentials**

#### 5. ช่องทางรับข้อความ

เส้นทาง: **Admin → ระบบดูดวง → ช่องทางรับข้อความ**

- ดูสถิติแต่ละช่องทาง (Facebook, LINE)
- ตั้งค่า LINE Official Account
- ตั้งค่าปุ่ม Get Started สำหรับ Facebook
- ทดสอบการเชื่อมต่อ

#### 6. เทมเพลตตอบกลับ

เส้นทาง: **Admin → ระบบดูดวง → เทมเพลตตอบกลับ**

ปรับแต่งข้อความ:
- ข้อความต้อนรับ
- ข้อความคำทำนายพื้นฐาน
- ข้อความคำทำนายละเอียด
- ข้อความแจ้งชำระเงิน
- ข้อความ Error

## FAQ และการแก้ปัญหา

### ลูกค้าไม่ได้รับคำทำนายหลังโอนเงิน

**สาเหตุที่เป็นไปได้:**
1. โอนยอดเงินไม่ตรง (เช่น 49.00 แทน 49.37)
2. SMS ยังไม่เข้าระบบ (รอ 1-2 นาที)
3. SMS Checker มีปัญหา

**วิธีแก้:**
1. ตรวจสอบที่ **Admin → จัดการบิล → บิลที่รอชำระ**
2. ค้นหาบิลจากเลขที่อ้างอิง
3. กด **"ยืนยันการชำระเงิน Manual"**

### ลูกค้าส่งข้อความแต่ไม่มีการตอบกลับ

**ตรวจสอบ:**
1. Webhook URL ถูกต้องหรือไม่
2. Page Access Token / Channel Access Token หมดอายุหรือไม่
3. ดู Log ที่ `storage/logs/laravel.log`

### AI ตอบช้าหรือ Error

**ตรวจสอบ:**
1. API Key ของ AI Provider ยังใช้งานได้
2. Rate Limit ยังไม่เต็ม
3. ลองเปลี่ยน AI Provider (Grok → OpenAI)

### ข้อความแสดงผิดภาษา

**วิธีแก้:**
1. ไปที่ **Admin → เทมเพลตตอบกลับ**
2. แก้ไขเทมเพลตที่ต้องการ
3. ใช้ภาษาไทยทั้งหมด
