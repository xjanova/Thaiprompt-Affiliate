# Image Resources

Place your image assets in this directory.

## Required Images

### App Icon & Logo
- `logo.png` - App logo (200x200px recommended)
- `appicon.svg` - App icon in SVG format

### Icons for Navigation
- `dashboard_icon.png` - Dashboard icon
- `commission_icon.png` - Commission icon
- `referral_icon.png` - Referral icon
- `profile_icon.png` - Profile icon
- `logout_icon.png` - Logout icon

### Splash Screen
- `splash.svg` - Splash screen image

## Image Formats Supported
- PNG
- JPG
- SVG (recommended for icons)

## Best Practices
1. Use SVG for icons whenever possible
2. Use PNG with transparency for logos
3. Optimize images before adding them
4. Use appropriate resolutions:
   - Icons: 48x48 to 96x96
   - Logos: 200x200 to 512x512
   - Images: Up to 2048x2048

## Auto-generated
MAUI will automatically generate different resolutions for different devices.
