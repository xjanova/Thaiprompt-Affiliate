# คู่มือผู้ใช้ระบบ OCR/KYC ที่อัจฉริยะ

## 🎯 ฟีเจอร์ใหม่

### 1. **ระบบถ่ายรูปด้วยกล้อง พร้อมกรอบเล็งบัตร**
- เปิดกล้องโดยตรงจากหน้าอัพโหลด
- กรอบสี่เหลี่ยมช่วยวางตำแหน่งบัตรให้ถูกต้อง
- มุมกรอบสีเขียวบอกตำแหน่งที่ดีที่สุด
- สลับกล้องหน้า-หลังได้

### 2. **ตรวจสอบคุณภาพรูปอัตโนมัติ**
ระบบจะตรวจสอบรูปก่อน OCR:
- ✅ ขนาดไฟล์ (ต้องมากกว่า 10KB)
- ✅ ความละเอียด (อย่างน้อย 300x200 pixels)
- ✅ รูปแบบไฟล์ (JPEG, PNG)
- ✅ ความถูกต้องของข้อมูลรูปภาพ

### 3. **ปรับปรุงรูปอัตโนมัติ**
ก่อนส่งไป OCR ระบบจะ:
- เพิ่มความสว่างและคอนทราสต์
- ทำให้รูปคมชัดขึ้น (Sharpen)
- แปลงเป็น JPEG คุณภาพสูง (95%)

### 4. **แจ้งข้อผิดพลาดที่ชัดเจน**
เมื่อ OCR อ่านไม่ได้ ระบบจะบอกว่า:
- **ไม่พบไฟล์รูปภาพ** → กรุณาอัพโหลดรูปภาพใหม่อีกครั้ง
- **ไฟล์รูปภาพมีขนาดเล็กเกินไป** → ใช้รูปถ่ายจากกล้อง ไม่ใช่ screenshot
- **ความละเอียดต่ำเกินไป (300x200)** → ถ่ายใหม่ให้ละเอียดกว่านี้ (แนะนำ 800x600+)
- **ไม่สามารถตรวจจับข้อความได้** → ถ่ายรูปให้ชัดเจน มีแสงสว่างเพียงพอ
- **ตรวจพบข้อความบางส่วน แต่ไม่เพียงพอ** → ถ่ายบัตรทั้งใบให้เห็นชัดเจน

## 📱 วิธีใช้งาน

### วิธีที่ 1: ถ่ายรูปด้วยกล้อง (แนะนำ)

1. **เข้าหน้าอัพโหลด KYC**
   - ไปที่ `/user/kyc/create`

2. **คลิก "เปิดกล้องถ่ายรูป"**
   - อนุญาตการเข้าถึงกล้อง
   - กรอบสี่เหลี่ยมจะปรากฏขึ้น

3. **วางบัตรในกรอบ**
   - วางบัตรประชาชน/ใบขับขี่ให้อยู่ในกรอบสีขาว
   - ให้มุมบัตรตรงกับมุมสีเขียว
   - ตรวจสอบว่าข้อความบนบัตรอ่านได้ชัดเจน

4. **ถ่ายรูป**
   - คลิกปุ่มถ่ายรูป (วงกลมสีแดง)
   - ตรวจสอบรูปที่ถ่าย
   - ถ้าไม่ชอบ คลิก "ถ่ายใหม่"
   - ถ้าพอใจ คลิก "ใช้รูปนี้"

5. **ส่งคำขอ**
   - ทำซ้ำกับรูปถ่ายตัวเอง
   - คลิก "ส่งคำขอยืนยันตัวตน"

### วิธีที่ 2: เลือกรูปจากคลัง

1. คลิก "เลือกจากคลัง"
2. เลือกรูปบัตรจากคลังภาพ
3. ตรวจสอบ preview
4. ส่งคำขอ

- ✅ **แสงสว่างเพียงพอ** - ถ่ายในที่แสงธรรมชาติหรือแสงไฟที่สว่าง
- ✅ **บัตรเรียบ** - วางบัตรบนพื้นเรียบ ไม่บิดเบี้ยว
- ✅ **ถ่ายทั้งใบ** - ให้เห็นขอบบัตรทั้ง 4 ด้าน
- ✅ **ตั้งฉาก** - ถ่ายจากด้านบน ไม่เอียง
- ✅ **ไม่เบลอ** - กดชัตเตอร์แล้วรอให้ภาพคงที่
- ❌ **หลีกเลี่ยงแสงสะท้อน** - อย่าให้แสงสะท้อนบนพลาสติกบัตร

### สำหรับรูปถ่ายตัวเอง:
- ✅ **ถือบัตรไว้ใกล้ใบหน้า** - ให้เห็นทั้งหน้าและบัตรชัดเจน
- ✅ **แสงสว่าง** - ถ่ายในที่มีแสงสว่าง ไม่ด้านหลัง
- ✅ **ไม่ปิดบังใบหน้า** - ไม่ใส่หมวก แว่นตาดำ
- ✅ **สีหน้าเป็นธรรมชาติ** - ไม่ต้องยิ้ม สีหน้าปกติ

## 🔍 สาเหตุที่ OCR อ่านไม่ได้

### 1. **รูปมืดหรือเบลอ**
**สาเหตุ:**
- ถ่ายในที่แสงน้อย
- กล้องไม่โฟกัส
- สั่นมือขณะถ่าย

**วิธีแก้:**
- ถ่ายใหม่ในที่แสงสว่างเพียงพอ
- รอให้กล้องโฟกัสก่อนกดถ่าย
- จับโทรศัพท์ให้มั่น หรือใช้ตัวตั้ง

### 2. **บัตรเอียงหรือบิดเบี้ยว**
**สาเหตุ:**
- ถ่ายจากมุมเฉียง
- บัตรโค้งงอ

**วิธีแก้:**
- วางบัตรเรียบบนพื้นเรียบ
- ถ่ายจากด้านบน ตั้งฉาก 90 องศา
- ใช้กรอบเล็งในโหมดถ่ายรูป

### 3. **แสงสะท้อน (Glare)**
**สาเหตุ:**
- แฟลชหรือแสงไฟสะท้อนบนพลาสติกบัตร

**วิธีแก้:**
- ปิดแฟลช
- เอียงบัตรเล็กน้อยเพื่อหลีกเลี่ยงแสงสะท้อน
- ถ่ายในที่มีแสงสม่ำเสมอ ไม่มีแสงจุด

### 4. **ความละเอียดต่ำเกินไป**
**สาเหตุ:**
- ใช้กล้องคุณภาพต่ำ
- บัตรเล็กเกินไปในภาพ
- Screenshot หน้าจอ

**วิธีแก้:**
- เข้าใกล้บัตรมากขึ้น
- ใช้กล้องหลัก ไม่ใช่กล้องหน้า
- ถ่ายรูปใหม่ ไม่ใช้ screenshot

### 5. **บัตรไม่อยู่ในภาพ**
**สาเหตุ:**
- ถ่ายเฉพาะบางส่วนของบัตร
- ครอบตัดขอบบัตรออก

**วิธีแก้:**
- ถ่ายให้เห็นบัตรทั้งใบ
- ให้ขอบบัตรอยู่ในกรอบทั้ง 4 ด้าน

## 🔧 Troubleshooting

### ปัญหา: กล้องไม่เปิด
**สาเหตุ:** เบราว์เซอร์ไม่อนุญาตการเข้าถึงกล้อง

**วิธีแก้:**
1. ตรวจสอบว่าเว็บใช้ HTTPS
2. ไปที่การตั้งค่าเบราว์เซอร์ → Privacy & Security → Site Settings → Camera
3. อนุญาตการเข้าถึงกล้องสำหรับเว็บนี้

### ปัญหา: OCR อ่านไม่ได้เสมอ
**คำแนะนำ:**
- ลองถ่ายรูปใหม่หลายๆ รูป เลือกรูปที่ชัดที่สุด
- ตรวจสอบว่ารูปที่ถ่ายมีความละเอียดอย่างน้อย 800x600 pixels
- ถ่ายในที่แสงสว่างธรรมชาติ (กลางวัน)
- อย่าใช้รูป screenshot หรือรูปที่ถ่ายจากจอคอมพิวเตอร์

### ปัญหา: แจ้งว่า "ระบบ OCR ยังไม่พร้อมใช้งาน"
**สาเหตุ:** ผู้ดูแลระบบยังไม่ได้ตั้งค่า Google Cloud Vision API

**วิธีแก้:**
- ติดต่อผู้ดูแลระบบ
- ในระหว่างนี้ยังสามารถส่งคำขอ KYC ได้ แอดมินจะกรอกข้อมูลด้วยตนเอง
