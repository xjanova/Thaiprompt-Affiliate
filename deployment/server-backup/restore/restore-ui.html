♻️ กู้คืนเครื่องจากชุดสำรอง

ทำตามทีละขั้นจากบนลงล่าง ข้อมูลลับอยู่ในหน่วยความจำของเครื่องนี้เท่านั้น และกด “ล้างกุญแจและปิด” เมื่อเสร็จ

1 เชื่อมต่อชุดสำรอง

ถ้าเครื่องใหม่ใช้ IP ต่างจากเดิม ให้สร้าง token ใหม่ใน Cloudflare (R2 → Manage API tokens → Object Read only, bucket thaiprompt-backup) แล้วลบทิ้งหลังกู้เสร็จ

2 เลือกเครื่องและชุดสำรอง

3 ตรวจและเลือกขั้นตอน

ขั้นที่ล้มจะหยุดรอ แก้แล้วกดเริ่มใหม่จากขั้นนั้นได้ (ติ๊กเฉพาะขั้นที่เหลือ)

4 กำลังกู้คืน
