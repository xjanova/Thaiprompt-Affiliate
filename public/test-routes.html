🔧 ทดสอบเมนู TPIX Blockchain & Token Management

📌 คำแนะนำ: คลิกลิงก์ด้านล่างเพื่อทดสอบว่า routes ทำงานหรือไม่
ถ้าได้หน้า "404 Not Found" แสดงว่า route ไม่ทำงาน
ถ้าได้หน้า "403 Forbidden" หรือ redirect ไป login แสดงว่า route ทำงาน แต่ต้อง login เป็น admin

⛓️ TPIX Blockchain Routes

🏠 TPIX Dashboard
GET /admin/tpix/dashboard
 🌐 Network Status
GET /admin/tpix/network-status
 👛 Wallets
GET /admin/tpix/wallets
 💸 Transactions
GET /admin/tpix/transactions
 ⚙️ Settings
GET /admin/tpix/settings

💎 Token Management Routes

📋 Token ทั้งหมด
GET /admin/tokens
 ⏳ รออนุมัติ
GET /admin/tokens?status=draft
 ✅ Verified Tokens
GET /admin/tokens?verified=1
 🔗 Import from CMC
GET /admin/tokens/import-cmc

✅ Other Working Routes (for comparison)

🏠 Admin Dashboard
GET /admin/dashboard
 ₿ Crypto Dashboard
GET /admin/crypto/dashboard
⚠️ หมายเหตุ:
- ต้อง login เป็น admin ก่อนถึงจะเข้าถึง routes เหล่านี้ได้
- ถ้าคลิกแล้วได้ 404 Not Found แสดงว่า routes ไม่ทำงาน
- ถ้า redirect ไป login หรือได้ 403 แสดงว่า routes ทำงาน
- ถ้าเข้าหน้าได้ปกติ แสดงว่าทุกอย่างสมบูรณ์แล้ว ✅
